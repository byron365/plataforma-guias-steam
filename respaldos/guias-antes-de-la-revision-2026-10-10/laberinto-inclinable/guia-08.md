# Guía 8 · Preparando el gran torneo

## Objetivo del día

Definir las reglas del torneo de laberintos, practicar, y preparar el guion y el cartel de la presentación.

**Al terminar tendremos:** reglas del torneo acordadas por todo el grupo, el guion con responsables y el cartel empezado.

## Materiales del equipo

- Laberinto completo
- Ficha técnica y tabla de tiempos (sábado 7)
- Cartulina y marcadores

## Parte 1 · Las reglas del torneo (25 min)

Cada equipo propone reglas y luego el grupo vota. Piensen en:

:::tabla id="g8-reglas"
| Tema | Nuestra propuesta |
| --- | --- |
| ¿Cuántos intentos tiene cada jugador? | |
| ¿Se juega en el laberinto propio o en el de otros equipos? | |
| ¿Qué pasa si la canica se sale del tablero? | |
| ¿Hay tiempo máximo por intento? | |
| ¿Cómo se gana: mejor tiempo o promedio? | |
| ¿Hay premio al laberinto más difícil? | |
:::

Reglas votadas por el grupo:

:::pregunta id="g8-p1"
Escribe las reglas finales que eligió el grupo.
:::

## Parte 3 · Guion de la presentación (30 min)

Antes del torneo, cada equipo presenta su laberinto en **5 minutos**:

:::tabla id="g8-guion"
| Parte | Tiempo | ¿Qué se dice o se muestra? | Quién |
| --- | --- | --- | --- |
| La idea y el diseño del laberinto | 1 min | | |
| El cardán y el diseño 3D | 1 min | | |
| El circuito y el código (suavizado, sensor) | 1 min | | |
| Datos: tiempos y récord | 1 min | | |
| Demostración en vivo | 1 min | | |
:::

## Parte 4 · Cartel (15 min)

El cartel debe tener: nombre del equipo, foto o render del laberinto, el mapa del laberinto con coordenadas, la ficha técnica y el récord del equipo.

## ¿Lo logramos? (5 min)

:::checklist id="g8-logramos"
- [ ] Propusimos y votamos las reglas.
- [ ] Practicamos en dos laberintos.
- [ ] El guion tiene responsables.
- [ ] Empezamos el cartel.
:::

## Reto extra

Diseñen un **desafío sorpresa** para el torneo, por ejemplo: jugar con el joystick al revés, o con los ojos vendados guiado por un compañero.
