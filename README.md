# Plataforma de guías · STEAM Robotics Academy

Plataforma web local (sin internet) para que los equipos sigan las guías de proyectos de robótica desde
celulares, tabletas o computadoras conectados al mismo Wi-Fi: guías paso a paso con animaciones,
respuestas que se guardan solas, fotos, archivos de trabajo, bitácora del equipo y panel del docente.

- **Cómo usarla:** [`LEEME.md`](LEEME.md)
- **Cómo agregar proyectos y escribir guías:** [`COMO_AGREGAR_PROYECTOS.md`](COMO_AGREGAR_PROYECTOS.md)
- **Estado del desarrollo y pendientes:** [`ESTADO_DEL_PROYECTO.md`](ESTADO_DEL_PROYECTO.md)
- **Registro de la revisión de las guías:** [`REVISION_GUIAS.md`](REVISION_GUIAS.md)

Hecha con Node.js (Express, better-sqlite3, marked). Docente: Bairon Alas.
