# Guía 8 · Listos para el reto

## Objetivo del día

Practicar el reto final, preparar lo que vamos a decir y ensayar la presentación completa.

**Al terminar tendremos:** nuestro mejor tiempo registrado, un guion con lo que dice cada integrante y un cartel del proyecto.

## Materiales del equipo

- Garra funcionando (modo manual y automático)
- 5 objetos del reto y un vaso
- Cronómetro (celular)
- Cartulina, marcadores, fotos impresas o computadora
- Ficha técnica del sábado 7

## Parte 1 · Las reglas del reto (10 min)

> **Reto final:** mover 5 objetos de la mesa al vaso en el menor tiempo posible, usando las perillas. Si un objeto cae fuera del vaso, se vuelve a colocar y el reloj sigue. Después se muestra la rutina automática con el botón.

Lean las reglas en voz alta y asegúrense de que todos las entendieron. Si tienen dudas, pregúntenlas ahora al docente.

:::pregunta id="g8-p1"
¿Qué objeto deberían mover primero y por qué?
:::

## Parte 2 · Práctica cronometrada (30 min)

Antes de empezar: conecten el circuito, suban el programa `equipo_NOMBRE_rutina` (Guía 7) y comprueben que las cuatro perillas responden.

Cada integrante intenta el reto. Anoten los tiempos:

1. Coloquen los 5 objetos en la mesa y el vaso al otro lado, siempre en los mismos lugares (márquenlos con cinta para que todos los intentos sean iguales).
2. Una persona maneja las perillas, otra cronometra con el celular y otra anota.
3. El reloj empieza cuando el piloto toca la primera perilla y para cuando cae el quinto objeto en el vaso.
4. Escriban cada tiempo en segundos. En "Mejor tiempo" pongan el más pequeño de los tres intentos de esa persona.

| Integrante | Intento 1 (s) | Intento 2 (s) | Intento 3 (s) | Mejor tiempo |
| --- | --- | --- | --- | --- |
| | | | | |
| | | | | |
| | | | | |
| | | | | |

Elijan como piloto a quien tuvo el mejor tiempo (o a quien se sienta más seguro).

Nuestro piloto para la presentación será: ______

:::pregunta id="g8-estrategias"
¿Qué estrategias nos funcionaron?
:::

Ahora prueben la rutina automática: dejen las perillas cerca del centro, pongan un objeto en su lugar y presionen el botón. Repítanlo tres veces.

:::

## Parte 3 · Nuestro guion (25 min)

La presentación dura **4 minutos** antes del reto. Cada integrante habla de una parte:

1. Repartan las cuatro partes: escriban un nombre en la columna **Quién**.
2. Para cada parte, escriban en **¿Qué decimos?** 2 o 3 ideas cortas. Ideas de ayuda:
   - **Presentación:** nombre del equipo, quiénes somos, qué construimos.
   - **Diseño en Blender:** qué piezas modelamos y por qué el hueco lleva holgura.
   - **Electrónica y código:** por qué usamos pilas y GND común, qué hacen las perillas y el botón.
   - **Lo que aprendimos:** lo más difícil y cómo lo resolvimos.
3. Practiquen con el cronómetro: cada parte no debe pasar de su tiempo.

| Parte | Tiempo | ¿Qué decimos? | Quién |
| --- | --- | --- | --- |
| 1. Presentación | 30 s | | |
| 2. Diseño en Blender | 1 min | | |
| 3. Electrónica y código | 1 min 30 s | | |
| 4. Lo que aprendimos | 1 min | | |

Escriban 2 o 3 frases clave por parte. No hace falta memorizar: solo saber qué contar.

## Parte 4 · Cartel del proyecto (25 min)

Hagan un cartel (cartulina o una diapositiva) con estas secciones:

1. Nombre del equipo y del proyecto.
2. Foto o dibujo de la garra.
3. Las 4 articulaciones y sus servos.
4. Diagrama de flujo (sábado 3).
5. Nuestro mejor tiempo.

Consejos para que se lea desde lejos:

- Primero dibujen a lápiz dónde irá cada sección; después pasen a marcador.
- Letras grandes en el título (que se lea a tres pasos) y frases cortas.
- Pueden imprimir fotos de la bitácora o dibujarlas.

## Parte 5 · Ensayo con otro equipo (15 min)

Preséntense entre dos equipos. El equipo que escucha nos dice:

1. Un equipo presenta completo (guion de 4 minutos) mientras el otro escucha sin interrumpir.
2. Al final, el equipo que escuchó dice lo mejor, algo que pueden mejorar y una pregunta. Ustedes lo escriben en la tabla.
3. Cambian los papeles.

## ¿Lo logramos? (5 min)

:::checklist id="g8-logramos"
- [ ] Todos practicamos el reto y tenemos tiempos.
- [ ] Elegimos piloto.
- [ ] El guion tiene responsable para cada parte.
- [ ] El cartel está terminado.
- [ ] Ensayamos y recibimos comentarios.
:::

## Reto extra

:::pregunta id="g8-reto"
Preparen una respuesta corta para la pregunta que más probablemente les harán: "¿Qué mejorarían si lo volvieran a hacer?"
:::

## Bitácora (10 min)

Nuestro mejor tiempo hoy: ______ s

:::pregunta id="g8-b1"
¿Qué comentario del otro equipo nos sirvió más?
:::

:::pregunta id="g8-b2"
¿Qué revisaremos antes de presentar? (pilas, tornillos, cables)
:::

- Recomendar traer pilas nuevas el día de la presentación.

:::
